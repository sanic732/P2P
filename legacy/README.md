# Legacy — история версий P2P

> Как читать историю. Здесь хранится **эволюция поколений v1 → v8** (тексты, описания, changelog) — для демонстрации развития проекта. Это **не копия** старого EN-репозитория [`P2P`](https://github.com/sanic732/P2P-v1-legacy) (он заархивирован отдельно read-only).

## Что где

- `HISTORY.md` — связный рассказ об эволюции проекта (RU + EN-резюме).
- `v<N>/DESCRIPTION.md` — карточка каждого поколения (RU+EN): какую боль решало, что нового, состав файлов, ссылка на форум-пост.
- Сводный changelog всех поколений — в корневом `../CHANGELOG.md` (записи `(backfilled)`).
