# /p2p-explore — Exploration Mode

**Что делает:** Активирует Exploration Mode для дивергентного мышления.

**Использование:**
```
/p2p-explore [тема/проблема]
```

**Поведение:**
- Переключается в Exploration Mode
- Все гипотезы помечаются [EXP: ...]
- Нестандартные идеи помечаются [UNCONVENTIONAL]
- Финальное ранжирование по вероятности успеха

**Выход:** `EXIT EXPLORATION` или `/p2p-scope`
