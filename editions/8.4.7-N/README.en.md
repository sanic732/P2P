## Who it's for
Anyone whose model isn't 'native' (GPT, DeepSeek, Qwen, Kimi, GLM, Gemini…). The easiest to launch.

## What makes it different
A vendor-agnostic universal preloader. `!!core_v8N.md` rewrites syntax on the fly per host (JSON for GPT, native reasoning for DeepSeek, strict Markdown for GLM).
