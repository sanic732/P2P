# Базовые коды 4PDA

Источник: справка форума `index.php?act=legends&CODE=bbcode` (снята 08.08.2026)
и тема 179679 «Оформление сообщений». Регистр тегов значения не имеет.

## Официальный перечень

| Группа | Теги |
|---|---|
| текст | `[B]` `[I]` `[U]` `[S]` (зачёркнутый) |
| размер, шрифт, цвет | `[SIZE=7]` `[FONT="times"]` `[COLOR=red]` `[BACKGROUND=skyblue]` |
| ссылки | `[URL]` · `[URL="…"]текст[/URL]` · `[EMAIL]` · `[EMAIL="…"]текст[/EMAIL]` |
| списки | `[LIST]` · нумерация `[LIST=1]` `[LIST=I]` `[LIST=i]` `[LIST=A]` `[LIST=a]`, пункты `[*]` |
| выравнивание | `[LEFT]` `[CENTER]` `[RIGHT]` |
| блоки | `[QUOTE]` · `[QUOTE="имя"]` · `[QUOTE name="…" date="…" post="…"]` |
| | `[CODE]` · `[CODE="заголовок"]` |
| | `[SPOILER]` · `[SPOILER="заголовок"]` |
| | `[HIDE]` · `[HIDE=5]` — видно написавшим не меньше 5 сообщений |
| прочее | `[SNAPBACK]<post_id>[/SNAPBACK]` · `[OFFTOP]` (мелкий серый) · `[ANCHOR]имя[/ANCHOR]` |
| вложения | `[attachment="<attach_id>:<имя>"]` |

`[BACKGROUND]`, `[OFFTOP]`, `[ANCHOR]`, `[HIDE=N]` и буквенная нумерация списков —
местные расширения 4PDA, в типовом IP.Board их нет.

## Как это пишется

```
[QUOTE]Цитируемый текст[/QUOTE]

[b]Жирный[/b]  [i]Курсив[/i]  [u]Подчёркнутый[/u]  [s]Зачёркнутый[/s]

[URL="https://4pda.to/forum/index.php?showtopic=1109539"]Название ссылки[/URL]

[COLOR=purple]Фиолетовый[/COLOR]
[COLOR=royalblue]Голубой[/COLOR]
[COLOR="#DB7093"]Произвольный цвет по HEX[/COLOR]

[SIZE=5]Увеличенный шрифт[/SIZE]
```

Списки — обычный, нумерованный, буквенный:

```
[list][*]текст[*]текст[/list]
[list=1][*]текст[*]текст[/list]
[list=A][*]текст[*]текст[/list]
```

## Скрытый текст

```
[hide]Скрыто от незарегистрированных[/hide]
[hide=50]Скрыто от написавших меньше 50 сообщений[/hide]
```

В теме 1109539 `[hide]` — не украшение, а одно из трёх условий публикации
материала по п. 3 правил раздела (см. `правила/R-правила-раздела.md`).

## Якорь

```
[anchor]NAZVANIE[/anchor]
```

Имя якоря — только латиница или цифры, без пробелов, регистр значим
(`Nazvanie` и `nazvanie` — разные якоря). Ссылка на якорь получается из значка,
который появляется в сохранённом сообщении. Полезно, когда нужно отправить
участника к конкретному пункту длинной инструкции, а не к посту целиком.

## Пермалинк на сообщение

```
https://4pda.to/forum/index.php?showtopic=<topic>&view=findpost&p=<post_id>
```

`showtopic` — ID темы, не меняется при переносе и переименовании.
Адрес копируется из «Сообщение #N» в правом верхнем углу поста,
а не из адресной строки браузера.

## Вложения

Имя загружаемого файла кириллицы содержать не должно (замечание из справки
2010 года; на практике кириллические имена встречаются, но полагаться на это
не стоит).
