# Edge-cases 4PDA: заголовки спойлеров, кавычки, вложенные теги

> Проверено на превью форума: рендер каждого варианта подтверждён
> скриншотом. Ниже — что 4PDA показывает на самом деле, а не что ожидается.

## ⛔ Главное правило (важное)

**Форматированный заголовок спойлера пишется БЕЗ внешних кавычек.**
Если обернуть теги во внешние кавычки — форум НЕ парсит их и выводит сырой код.

| Код | Рендер на форуме |
| :-- | :-- |
| `[SPOILER="Пример"]` | `Спойлер: Пример` (кавычки убраны, чистый текст) ✅ |
| `[SPOILER=[COLOR=Red][B]Пример[/B][/COLOR]]` | `Спойлер:` **Пример** (красный жирный) ✅ |
| `[SPOILER="[COLOR=Red][B]Пример[/B][/COLOR]"]` | `Спойлер: [COLOR=Red][B]Пример[/B][/COLOR]` — **сырой код буквально** ❌ |
| `[SPOILER=[COLOR=Red][B]"Пример"[/B][/COLOR]]` | `Спойлер:` **"Пример"** (красный жирный, кавычки — часть видимого текста) ✅ |

**Вывод:** кавычки — только вокруг ПРОСТОГО текста заголовка. Нужен цвет/жирность/
ссылка в заголовке — пишем теги БЕЗ внешних кавычек.

## Ссылка как заголовок спойлера

| Код | Рендер |
| :-- | :-- |
| `[URL=…p=143929735]ссылка[/URL]` | `ссылка` (синяя кликабельная) ✅ |
| `[COLOR=Red][URL=…]ссылка[/URL][/COLOR]` | `ссылка` — **остаётся синей** (цвет ссылки не перебивается `[COLOR]`) |
| `[SPOILER=[COLOR=Red][URL=…]ссылка[/URL][/COLOR]]` | `Спойлер:` ссылка (синяя кликабельная в заголовке) ✅ |
| `[SPOILER="[COLOR=Red][URL=…]ссылка[/URL][/COLOR]"]` | `Спойлер: [COLOR=Red][URL=…]ссылка[/URL][/COLOR]` — **сырой код** ❌ |

Нюансы: ссылку в заголовок спойлера класть можно (без внешних кавычек, кликабельность
сохраняется). Обёртка `[COLOR]` вокруг `[URL]` цвет ссылки НЕ меняет — она остаётся
ссылочно-синей.

## Правило по умолчанию

Форматированный заголовок спойлера пишется без внешних кавычек — это дефолт
для любого жанра: `[spoiler=Глава 2. [color=Teal]Название[/color]]`.
Внешние кавычки вокруг тегов не ставятся никогда.
