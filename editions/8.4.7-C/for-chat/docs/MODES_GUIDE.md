# P2P 8.4.7-C — Гайд по режимам

> Эти же баннеры ты увидишь в интерфейсе при переключении режима — здесь они с описанием,
> чтобы сразу узнавать «о, это тот самый режим». Если файл `!art.md` не загружен — баннеров не будет,
> но сами режимы работают.

---

## ✈ PILOT — насколько активно P2P тебе помогает

P2P подстраивает количество вопросов и автоматику под тебя. Меняется в шапке меню (клик или номер).

### CO-PILOT — для новичка (по умолчанию)
```text
    ✈   CO-PILOT  ·  веду за руку
  ◉─┼─◉  спрошу • подскажу • соберу за тебя
    │    режим новичка
```
P2P сначала задаст пару простых вопросов (на языке твоей задачи, без терминов), предложит варианты
кнопками/номерами и сам подберёт модель и настройки. Идеально, если ты не разбираешься в промптинге.

### AUTO-PILOT — баланс
```text
   ✈    AUTO-PILOT  ·  баланс
  [▸▸]  пара уточнений — дальше веду сам
   ⟳    средний режим
```
Минимум вопросов, разумные умолчания, краткие пояснения. Для тех, кто уже освоился.

### MANUAL — для опытного (+ GLASS COCKPIT)
```text
  ╔══ GLASS COCKPIT ══╗   MANUAL  ·  всё активно
  ║ ▪▪  ▪▪  ▪▪  ▪▪  ║   видишь все приборы:
  ╚═══════════════════╝   что и почему применено
```
Всё включено по умолчанию, минимум вопросов. **GLASS COCKPIT** показывает, какие техники и модули
P2P применил и почему — для тех, кто хочет тестировать и видеть «приборную панель».

## 🏔 SHERPA — проводник по возможностям среды
```text
        /\         SHERPA  ·  проводник по среде
       /  \    ▲   ⛰ покажу тропу — фичи, что ты не знал
      / ▲▲ \ ▲▲▲   идём вместе
     /▲▲▲▲▲▲▲▲▲▲\
```
Перед задачей SHERPA подскажет про штатные возможности твоей среды, о которых ты можешь не знать
(режим план, выбор мощности, настройки) — и предложит: сделать как обычно или через встроенную фичу.
Включён автоматически для новичка, выключается у эксперта. Команда `/sherpa` — вкл/выкл.

## Другие режимы с баннерами

**QUORUM** — совет 8 агентов для сложных задач (Tier 3-4):
```text
   ◉ ◉ ◉ ◉      QUORUM  ·  совет 8 агентов
   ◉  ⚖  ◉      спорят • голосуют → HELIOS сводит
   ◉ ◉ ◉ ◉      Tier 3-4
```

**SCOPE.HELM** — для больших проектов (разбивка + перенос контекста):
```text
       _⊕_        SCOPE.HELM  ·  большие проекты
     ⟋  |  ⟍    штурвал: SPLITTER → ROUTER → CAPSULE
    ⊙───┼───⊙    разбить • провести • донести контекст
        |
```

**EXPLORATION** — когда нужно несколько подходов к задаче:
```text
        N          EXPLORATION  ·  2-3 подхода
     W ─◈─ E       развилка: покажу разные пути
        S          для нестандартных задач
```

## Как сменить режим
- В меню: клик по `✈ РЕЖИМ ПИЛОТА` или напиши номер.
- Навсегда: в `_preloader.md` → `PILOT_MODE: co-pilot | auto-pilot | manual`.
- На одну сессию: скажи словами («я эксперт, без объяснений») — P2P поймёт (PERSONA_HINT).
