# Skill: Оптический executor P2P (pxpipe)

Это **исполнитель** («руки»). РЕШЕНИЕ *когда* сжимать принимает политика:
`compression.md` → **L-OPTICAL** (роутер сжатия) и `agents.md` → **PXPIPE_GATE**
(хендофф между агентами). Этот скилл только рендерит по команде и меряет выгоду.

## Что делает
Конвертирует текст в плотные PNG. Vision-модели тарифицируют картинку по площади
пикселей, а не по числу символов. На **реальном контенте P2P замерено ~81–83%
экономии токенов** (одна страница, ratio ~5×, режим <10× ≈ 97% точности по
DeepSeek-OCR, arXiv 2510.18234). Экономия — это математика пикселей, она
**не зависит от модели**; от модели зависит только *читаемость* (см. reader-gate).

## Три ЖЁСТКИХ гейта (не советы — enforcement в `compress.mjs`)
1. **READER GATE** — сжимать только для моделей, которые доказанно читают рендеры:
   **`claude-fable-5`**. Для Opus/Sonnet → **отказ** (путают ~7%, verbatim hex 0/15).
   `gpt-5.6` убран из гейта 2026-07-26 вслед за upstream: автор pxpipe вывел
   `gpt-5.6-sol` из дефолтного скоупа после raw-recall пилота — **0/4 точных
   идентификаторов и четыре выдуманных значения**, на обоих профилях (6×11 и 5×8).
   Читатель, который выдумывает идентификаторы, несовместим с запретом фабрикации.
   Обойти: `--force` (на свой риск).
2. **BYTE GUARD** — точные строки (SHA, ключи, `#DB_*`, id, пути, model-strings)
   вынимаются в **text-sidecar рядом с картинкой** (verbatim-safe, паттерн pxpipe).
3. **PROFIT GATE** — вход меньше `--min-chars` (деф. 8000) → отказ (мелочь проигрывает
   накладным расходам картинки).

## 🔴 ЧТО НЕЛЬЗЯ имиджировать (byte-exact — уходит в sidecar как текст)
Исходный код · JSON-конфиги · diff-патчи · точные хеши/ID коммитов · ключи API ·
консольные команды для копипаста. **РАЗРЕШЕНО:** аналитику, логи рассуждений,
словесные описания архитектуры, историю QUORUM, длинные разборы.

**DECISION LEDGER (MUST):** ключевые ЧИСЛА хендоффа (пороги, проценты, суммы,
размеры) дублируй коротким текстовым списком рядом с картинкой. Слепой тест на
Fable 5 (2026-07-07, плотная страница 1568×488): гист/слова — **7/7**, точные
числа/hex — **0/4, тихие конфабуляции** ($38.61→«$16.61» уверенно). Числам с
картинки не доверять — только sidecar/ledger.

## Установка (один раз, портируемо)
```bash
cd .claude/skills/pxpipe && npm install     # ставит pxpipe-proxy + gpt-tokenizer
```
Рендер работает БЕЗ нативного canvas в рантайме (атлас глифов вшит на build-time).

## Использование
```bash
# сжать хендофф для следующего агента (Fable 5 по умолчанию):
node .claude/skills/pxpipe/compress.mjs report.md --reader claude-fable-5

# только измерить выгоду (токенайзер), без записи PNG для передачи:
node .claude/skills/pxpipe/measure.mjs report.md --reflow
```
`compress.mjs` печатает markdown-ссылки на PNG + (если нужно) sidecar. Приложи
**картинки вместо** длинного текста, а **sidecar — как обычный текст**:

> «HELIOS, ниже оптически сжатый отчёт (Fable 5 читает его нативно). Изображения:
> `![p1](file:///.../px_ab12_p1.png)` — и точные идентификаторы текстом ниже.»

## Файлы
- `compress.mjs` — executor (3 гейта + sidecar + замер).
- `measure.mjs` — токенайзер-замер (text-tokens vs image-tokens, ratio, savings %).
- `byte-guard.mjs` — сканер byte-exact → sidecar.
- `lib-resolve.mjs` — портируемый резолвер pxpipe (npm-пакет → env → sibling).
