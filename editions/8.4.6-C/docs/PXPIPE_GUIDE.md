# pxpipe в P2P 8.4.3-C — оптическая экономия токенов

> Кратко: длинный текст рендерится в плотную PNG-картинку; vision-модель тарифицирует
> картинку **по площади пикселей**, а не по числу символов. На реальном контенте P2P это
> даёт **~82% экономии токенов на блок**, а в прокси-режиме — до **93%** на тёплом кэше.
> Работает **только на Claude Fable 5** (и GPT-5.6). Основано на
> [teamchong/pxpipe](https://github.com/teamchong/pxpipe) (MIT) и DeepSeek-OCR
> (arXiv [2510.18234](https://arxiv.org/abs/2510.18234)).

## Теория на пальцах

1. **Текст**: токен ≈ 2–4 символа. 25 000 символов ≈ 8 000 токенов — всегда.
2. **Картинка**: биллинг `ширина × высота ÷ 750` — **независимо от содержимого**.
   Страница 1568×648 стоит ~1 355 токенов, хоть пустая, хоть забитая микрошрифтом.
3. **Трюк**: рендерим текст ячейками 5×8 px с уплотнением строк (reflow) — в одну
   страницу влезает ~25k символов. 8 000 «текстовых» токенов → ~1 400 «пиксельных».
4. **Почему только Fable 5**: зрение — не сканер. Модель узнаёт текст как образ и
   достраивает языковой интуицией. Fable 5 читает плотность 4–5 px/глиф почти идеально;
   Opus на ней путает ~7% (verbatim hex 0/15) — поэтому отсекается гейтом.
5. **Цена канала**: слова/решения читаются 100%, а точные строки (хеши, суммы, проценты)
   могут «тихо конфабулироваться» — модель уверенно читает похожее-но-неверное.
   Поэтому byte-exact ВСЕГДА едет обычным текстом рядом с картинкой (sidecar/ledger).

## Замеры (реальные, воспроизводимые)

| Что | text-ток → img-ток | Экономия |
|---|---|---|
| core.md (25k симв) | 7 959 → 1 372 | **82.8%** |
| история QUORUM (54k) | 16 592 → 2 945 | **82.3%** |
| прокси: холодный ход (89k слэба → 4 PNG) | eff 24 310 vs 51 790 | **53.1%** |
| прокси: тёплый ход той же сессии (cache-hit) | eff 804 vs 12 454 | **93.5%** |

Слепой тест читаемости (Fable 5, плотная страница): смысл/имена/решения — **7/7**,
точные числа/hex — **0/4** (тихие конфабуляции) → правило DECISION LEDGER обязательно.

## Три слоя в P2P (что когда включается)

| Слой | Где живёт | Когда |
|---|---|---|
| **A · L-OPTICAL** | модуль compression (меню [38]) | контекст распух / нарратив ≥8000 симв → P2P сам предлагает сжать блок |
| **B · прокси** | команда `/p2p-pxpipe` | весь трафик сессии жмётся на проводе (только терминальная CLI, см. ниже) |
| **C · хендофф** | agents.md → PXPIPE_GATE; CAPSULE optical-backend | передача истории QUORUM агенту-синтезатору; большие CAPSULE |

Если включён прокси (B) — слои A/C глушатся автоматически (`PXPIPE_PROXY_ACTIVE`),
чтобы не сжимать дважды.

## Установка executor-скилла (один раз)

```bash
cd .claude/skills/pxpipe && npm install   # ставит pxpipe-proxy + gpt-tokenizer
```
Нужен Node ≥18. Рендер работает без нативных зависимостей (атлас глифов вшит).

## Использование

```bash
# сжать нарратив для следующего агента (гейты сработают сами):
node .claude/skills/pxpipe/compress.mjs report.md --reader claude-fable-5

# только замерить выгоду (ничего не отправляется):
node .claude/skills/pxpipe/measure.mjs report.md --reflow
```

`compress.mjs` печатает markdown-ссылки на PNG + текстовый sidecar с byte-exact
строками. Картинки вставляются ВМЕСТО простыни текста, sidecar — как обычный текст.

### Прокси-режим (максимальный ROI, терминальная CLI)

```bash
npx pxpipe-proxy                                   # сервер на 127.0.0.1:47821 + дашборд
ANTHROPIC_BASE_URL=http://127.0.0.1:47821 claude   # CLI через прокси
```
Прокси сам жмёт системный промпт, tool docs и старую историю; свежие ходы и ответы
модели не трогает. Замеры пишутся в `~/.pxpipe/events.jsonl`, дашборд — на `:47821`.
Desktop-приложение переменную не подхватывает из коробки; вариант — прописать
`"env": {"ANTHROPIC_BASE_URL": "http://127.0.0.1:47821"}` в `~/.claude/settings.json`
(тогда действует и на приложение; прокси должен быть запущен — иначе убрать ключ).

#### ⚠ Safety-refusal у Fable 5 на одиночных PNG — обязателен порог 24000

Найдено 2026-07-07 на живом трафике (`~/.pxpipe/events.jsonl`): запросы профиля
«**один PNG** со static-слэбом ~16k символов + почти нет обычного текста» — типичный
headless `claude -p` — Fable 5 систематически флагает: `stop_reason: refusal`,
`safety_flagged: true` (~70%, 5 из 7 запросов). Многокартиночные сжатые запросы
(4–5 PNG, длинные сессии) не флагаются — проверено 15/15 после фикса.

Фикс — не жать мелкие слэбы: запускать прокси с **`PXPIPE_MIN_COMPRESS_CHARS=24000`**.
Слэбы <24k идут passthrough (обычным текстом), большие сессии жмутся как раньше —
они дают multi-PNG и не попадают под refusal-профиль.

⚠ Upstream `pxpipe-proxy` v0.8.0 эту env-переменную **не читает** — требуется патч
фабрики `transform:` в `main()` файла `node_modules/pxpipe-proxy/dist/node.js`
(env `PXPIPE_MIN_COMPRESS_CHARS` >0 → `minCompressChars`), пока
[upstream](https://github.com/teamchong/pxpipe) не добавит ручку. Патч живёт в
`node_modules` и **перезатирается при `npm install`** — после переустановки повторить.

## Жёсткие правила (enforcement в коде, не пожелания)

1. **READER GATE** — reader не Fable 5 → отказ, текст остаётся текстом.
   (GPT-5.6 исключён в 8.4.6 вслед за upstream: пилот на точность дал 0/4 верных
   идентификаторов и четыре выдуманных значения.)
2. **PROFIT GATE** — < 8000 символов → отказ (картинка не окупится).
3. **BYTE-GUARD** — хеши, ключи, `#DB_*`, суммы, пути → текстовый sidecar автоматически.
4. **DECISION LEDGER** — ключевые числа хендоффа дублируются текстом. Числам с картинки не доверять.
5. **НЕ имиджировать**: исходный код, JSON-конфиги, diff, команды для копипаста.
