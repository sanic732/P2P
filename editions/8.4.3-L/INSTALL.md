# P2P v8L.3 — Установка (TL;DR)

> 8L.3 — **файловая сборка**: 4 BOOT-файла, вставляются в контекст любого хоста.
> Плагинной формы у Lite нет (см. «Почему нет плагина» ниже).

## Установка (любой хост: chat / API / Studio)

1. Склей 4 BOOT-файла из папки `boot/`:
   ```bash
   cat boot/_preloader_v8L.md boot/_index_v8L.md "boot/!!core_v8L.md" "boot/!!db_v8L.md" > boot_v8L.md
   ```
   (или просто вставь все 4 файла в контекст по очереди)
2. Вставь `boot_v8L.md` в контекст.
3. Система спросит хост → выбери `claude | gemini | gpt | grok | deepseek | qwen | kimi | glm`.
4. **⚠ Сразу выполни `/p2p-verify` (пункт 35)** — система реально дёрнет все Gist-URL и сверит
   sha256 + EOF-маркеры + размеры. **Работай только после успешного отчёта.**
5. Напиши `СТАРТ` — арсенал подтянется по триггеру.

## Требования

- **Хост с включённым инструментом веб-доступа** — арсенал (QUORUM/RAG/optimization) живёт на Gist:
  Gemini — grounding/поиск · GPT — browsing · Claude — WebFetch · Grok — X/web · Kimi — Agent/web ·
  Qwen/GLM/DeepSeek — провайдерский web-tool.
- Не проходит `/p2p-verify` → включи веб-доступ в настройках хоста и повтори.
- Проверено 2026-07-14: claude · gemini · gpt · grok · deepseek · qwen — fetch отрабатывает штатно.

## Почему у Lite нет плагина

Плагинная форма (`.claude/`) удалена намеренно (2026-07-14). Причина: команды и файлы Lite
пересекались бы с Claude Edition (8C.3) — при установке обоих плагинов в Claude Code они
«заражали» бы друг друга одноимёнными командами/скиллами. Lite — файловая сборка под любой хост;
для Claude Code/Cowork используй **8C.3 (`p2p-v8c3`)**.
