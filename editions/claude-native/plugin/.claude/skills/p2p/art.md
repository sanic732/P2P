# P2P v8C.3 — ART BANNERS (art.md)

> **ОПЦИОНАЛЬНЫЙ модуль. Чисто визуальный сахар.** Не загружай, если не нужен — функционал не меняется.
> Назначение: при ВЫБОРЕ режима, меняющего механику взаимодействия, показать компактный ASCII-баннер
> перед основным ответом — чтобы пользователь визуально узнавал режим (как логотип P2P на старте).
> Каждый режим — своя ассоциативная тема, чтобы легко различать.

## ПРАВИЛО ПОКАЗА
<art_rule>
  IF этот файл загружен AND пользователь переключает/выбирает один из режимов ниже:
    → показать соответствующий баннер ПЕРВЫМ, в отдельном code-fence, затем обычный ответ режима.
  IF файл НЕ загружен → работать без баннеров (graceful, никаких ошибок, никаких упоминаний).
  MUST NOT: показывать баннер чаще одного раза за переключение (не спамить на каждом сообщении).
  MUST NOT: показывать баннеры на Tier 0-1 без смены режима.
  MUST: держать баннер компактным — это акцент, а не стена арта.
  MUST: на стартовом меню — выводить баннеры СТРОГО ВЕРТИКАЛЬНО (один под другим, между ними пустая строка),
        НИКОГДА не по 2+ в ряд/в колонки; сразу под каждым баннером — строка выбора `→ <буква> — <режим>`.
</art_rule>

## CO-PILOT  (тема: авиация — второй пилот)
```text
    ✈   CO-PILOT  ·  веду за руку
  ◉─┼─◉  спрошу • подскажу • соберу за тебя
    │    режим новичка
```

## AUTO-PILOT  (тема: авиация — автопилот)
```text
   ✈    AUTO-PILOT  ·  баланс
  [▸▸]  пара уточнений — дальше веду сам
   ⟳    средний режим
```

## MANUAL + GLASS COCKPIT  (тема: авиация — приборная панель)
```text
  ╔══ GLASS COCKPIT ══╗   MANUAL  ·  всё активно
  ║ ▪▪  ▪▪  ▪▪  ▪▪  ║   видишь все приборы:
  ╚═══════════════════╝   что и почему применено
```

## SHERPA  (тема: горы — проводник)
```text
        /\         SHERPA  ·  проводник по среде
       /  \    ▲   ⛰ покажу тропу — фичи, что ты не знал
      / ▲▲ \ ▲▲▲   идём вместе
     /▲▲▲▲▲▲▲▲▲▲\
```

## QUORUM  (тема: совет — голоса агентов)
```text
   ◉ ◉ ◉ ◉      QUORUM  ·  совет 8 агентов
   ◉  ⚖  ◉      спорят • голосуют → HELIOS сводит
   ◉ ◉ ◉ ◉      Tier 3-4
```

## SCOPE.HELM  (тема: мореходство — штурвал)
```text
       _⊕_        SCOPE.HELM  ·  большие проекты

    ⊙───┼───⊙    разбить • провести • донести контекст
        |
```
