# P2P 8C.3 — FAQ и типовые ошибки

## FAQ

**Q: Чем 8C.3 отличается от H/N/L?**
A: Единственная редакция, заточенная под экосистему Claude: XML-ядро, установка плагином
одной командой, **нативные** sub-agents QUORUM (параллельный запуск), slash-команды,
pxpipe. На других LLM-хостах не работает — для них H/N/L. Агент ANON здесь безопасностник
(в других редакциях — кодер), код пишет сам Claude Code.

**Q: Какую форму поставки выбрать?**
A: Работаешь в Claude Code или Cowork → **plugin**. Работаешь в Claude.ai (чат, Projects,
API) → **for-chat**. Подробно: [INSTALL_GUIDE.md](INSTALL_GUIDE.md).

**Q: Какие модели поддерживаются?**
A: Fable 5, Opus 4.8/4.7/4.6, Sonnet 4.6, Haiku 4.5. Оптическое чтение pxpipe — **только
Fable 5** (Opus путает ~7% глифов — отсекается гейтом).

**Q: QUORUM в plugin-форме и for-chat — одно и то же?**
A: Логика и веса одни. В plugin-форме агенты — нативные sub-agents (изолированные контексты,
параллельно), в for-chat — симулируются в одном контексте. См. [AGENTS_GUIDE.md](AGENTS_GUIDE.md).

**Q: Что такое pxpipe и нужен ли он мне?**
A: Оптическое сжатие токенов (текст → PNG, ~82% экономии на блок). Нужен только на Fable 5
при больших сессиях/хендоффах. Целиком — [PXPIPE_GUIDE.md](PXPIPE_GUIDE.md).

**Q: Как обновиться?**
A: Маркетплейс: кнопка **Update** или `/plugin marketplace update P2P-4PDA-edition`
(загорается при поднятой версии в `plugin.json`). Бандл/for-chat: заменить файлы из свежего релиза.

## Типовые ошибки

### E1. «Unknown command: /p2p»
**Причина:** команды плагина требуют префикс имени плагина.
**Fix:** `/p2p-v8c3:p2p` (и так для всех: `/p2p-v8c3:p2p-quorum`…). Убрать префикс нельзя —
ограничение Claude Code для всех плагинов (issue #15882, closed «not planned»).

### E2. В Cowork нет slash-команд, хотя в Code есть
**Причина:** Cowork исполняет только **скиллы** (`.claude/skills/`), команды — механизм Code.
**Fix:** это не поломка. В Cowork используй скиллы: `p2p`, `p2p-quorum`, `p2p-teacher` и др. —
они дублируют ключевые команды.

### E3. Плагин не грузится целиком / команды пропали после обновления
**Причина (исторически):** битый YAML frontmatter в одном файле роняет ВЕСЬ плагин в Claude
Code (парсер строгий; Cowork мягкий и маскирует). Типовой убийца — незакавыченное значение
с `: ` внутри.
**Fix:** обновись до ≥8.4.2 (шапки вычищены и проверяются перед релизом). Если правишь
файлы сам — прогони frontmatter через pyyaml.

### E4. Кнопка Update не загорается
**Причина:** версия в `plugin.json` репо не выше установленной (Update смотрит только туда).
**Fix:** дождаться релиза с bump; проверить `/plugin marketplace update P2P-4PDA-edition`.

### E5. Команды «воскресают» после перезапуска / появился marketplace `local-desktop-app-uploads`
**Причина (исторически):** вложенный `marketplace.json` внутри плагина (footgun сборок ≤8.3.4).
**Fix:** удалить плагин и marketplace-призрак, поставить свежую версию (≥8.3.5 чистая).

### E6. pxpipe: «reader не поддерживается»
**Причина:** READER GATE — оптическое чтение только Fable 5 / GPT-5.6.
**Fix:** переключить сессию на Fable 5 или работать без имиджинга (`measure` доступен всем).

### E7. pxpipe-прокси: refusal на headless-запросах (`claude -p`)
**Причина:** Fable 5 систематически флагает запросы «один PNG почти без текста».
**Fix:** запускать прокси с `PXPIPE_MIN_COMPRESS_CHARS=24000` — подробности и патч в
[PXPIPE_GUIDE.md](PXPIPE_GUIDE.md) §Safety-refusal.

### E8. Ссылки вида `!teacher.md` не резолвятся в plugin-форме
**Причина (исторически):** for-chat имена файлов внутри плагина (вычищено в 8.3.5, ~234 ссылки).
**Fix:** обновиться; в plugin-форме модули зовутся `core.md`, `teacher.md`, `templates_library.md`…
