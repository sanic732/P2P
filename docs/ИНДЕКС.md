## Порядок загрузки модулей (для Projects/Chat метод)

```
1. _preloader.md         ← ENV detection
2. !!core_v8C.md         ← Меню, QUORUM, правила
3. !!db_v8C.md           ← G-errors, Templates
4. _live/MANIFEST.md     ← Дедлайны
5. _live/live_core.md    ← Состояние
6. _live/live_claude.md  ← Claude specs
```

После загрузки введи `СТАРТ` или `/p2p`.

**Для Cowork/Claude Code:** загрузка не нужна, ставится как plugin одним кликом.
См. [INSTALL_GUIDE.md](INSTALL_GUIDE.md) Метод 1.
