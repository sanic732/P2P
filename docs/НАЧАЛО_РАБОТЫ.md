## 🆕 Самый простой путь — `/p2p-teacher`

Если ты впервые видишь P2P — не читай эту инструкцию.
Запусти интерактивный курс:

```
/p2p-teacher
```

установку, команды, агентов и сложные сценарии. Подробнее: [TEACHER_GUIDE.md](TEACHER_GUIDE.md).

## Вариант A — Plugin для Cowork / Claude Code (рекомендуется) ⭐

**Шаг 1:** Собери `.plugin` файл из v8C.2:
```bash
# Linux/Mac:
bash pack.sh

# Windows:
powershell -ExecutionPolicy Bypass -File pack.ps1
```
→ получишь `p2p-v8c2.plugin` в родительской папке.

**Шаг 2:** Установи:
- **Cowork:** Settings → Skills → "+" → Upload a skill → выбери `.plugin`
- **Claude Code:** `/plugin install /path/to/p2p-v8c2.plugin`

**Шаг 3:** Готово:
```
/p2p              ← главное меню
/p2p-teacher      ← интерактивный курс
```

Полный гайд по 5 методам установки: [INSTALL_GUIDE.md](INSTALL_GUIDE.md).

## Вариант C — Claude Code (project-level)

**Шаг 1:** Скопируй каталог `.claude/` + корневые файлы в свой проект:
```bash
cp -r "cowork + code/.claude" /path/to/your-project/
cp "for chat (project)/"!*.md "for chat (project)/"!!*.md "for chat (project)/"_*.md /path/to/your-project/
cp -r "for chat (project)/_live" "for chat (project)/vendors" /path/to/your-project/
```

**Шаг 2:** Скопируй `p2p.config.md` в корень проекта и заполни:
```bash
cp "cowork + code/.claude/skills/p2p/p2p.config.md" /path/to/your-project/
```

**Шаг 3:** Открой проект в Claude Code → `/p2p`

## Вариант D — API

```python
import anthropic

client = anthropic.Anthropic()

# Собери system prompt (см. docs/ASSEMBLY_GUIDE.md)
files = [
    "_preloader.md", "!!core_v8C.md", "!!db_v8C.md",
    "_live/MANIFEST.md", "_live/live_core.md", "_live/live_claude.md"
]
system_prompt = "\n\n".join(open(f).read() for f in files)

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=4096,
    thinking={"type": "enabled", "effort": "medium"},
    system=[{
        "type": "text",
        "text": system_prompt,
        "cache_control": {"type": "ephemeral"}
    }],
    messages=[{"role": "user", "content": "СТАРТ"}]
)
```

⚠ **G7:** при `thinking=enabled` НЕ передавай `temperature` — HTTP 400.
⚠ **G8:** `budget_tokens` удалён из API — используй `effort: low/medium/high`.

## Первые команды

После загрузки попробуй:

| Команда | Что делает |
|---------|------------|
| `СТАРТ` или `/p2p` | Главное меню (34 пункта) |
| `/p2p-teacher` | 🎓 Интерактивный курс из 5 уровней |
| `[2]` | Contract Builder — сгенерировать промпт |
| `[6]` | Запустить QUORUM (8 агентов) |
| `[25]` | SCOPE.HELM для большой задачи |
| `/p2p-explore проблема` | Exploration Mode (brainstorm) |
| `/p2p-metrics` | Метрики сессии |

---

## Типичная сессия

```
1. Ввести СТАРТ → получить меню (34 пункта)
2. Описать задачу свободным текстом
3. P2P определит Tier (T0-T4) автоматически
4. Для T2+ предложит Contract Builder [2] или QUORUM [6]
5. Работать с агентами итеративно
6. При длинной сессии — /p2p-capsule для сохранения
```

## Устранение проблем

| Симптом | Решение |
|---------|---------|
| Claude игнорирует правила | `[21] CONSTRAINT REINJECTION` |
| HTTP 400 с Extended Thinking | Удали `temperature` из payload (G7) |
| Нет меню при СТАРТ | Проверь загрузку !!core_v8C.md |
| Агент не слышит MUST NOT | Добавь парные ограничения, см. !debug.md |
| Сессия слишком длинная | `/p2p-capsule save` → новая сессия |
| Не работает /p2p-teacher | Проверь что `!teacher.md` в корне (или `teacher.md` в skill folder) |
| Plugin не виден после Upload | Перезапусти Cowork (Cmd+R / Ctrl+R) |

Полный список проблем: [FAQ_И_ОШИБКИ.md](FAQ_И_ОШИБКИ.md), troubleshooting секция в [INSTALL_GUIDE.md](INSTALL_GUIDE.md).
