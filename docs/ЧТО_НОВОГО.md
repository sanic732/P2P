## 1. Plugin / Marketplace манифесты — установка в один клик

Раньше: копировать `.claude/`, потом BASE файлы, потом ON-DEMAND отдельно... 3 шага минимум.

Теперь: один `.plugin` файл.

**Что добавилось:**
- `.claude-plugin/plugin.json` — манифест для Claude Code / Cowork
- `.claude-plugin/marketplace.json` — манифест для git-distribution
- `pack.sh` (Linux/Mac) и `pack.ps1` (Windows) — упаковщики в `.plugin`

**Как пользоваться:**
```bash
bash pack.sh             # → p2p-v8c2.plugin
# Cowork: Settings → Skills → "+" → Upload a skill → выбрать .plugin
# Code:   /plugin install /path/to/p2p-v8c2.plugin
```

Marketplace путь (для команд):
```
/plugin marketplace add https://github.com/<user>/p2p
/plugin install p2p-v8c2@p2p
```

## 2. /p2p-teacher — интерактивный обучающий режим

P2P объективно сложная: 42 файла, 11 команд, 8 агентов, 5 режимов.
До v8C.2 — README + удачи. Теперь — проводник.

**Что добавилось:**
- `.claude/commands/p2p-teacher.md` — slash-команда
- `.claude/skills/p2p-teacher/SKILL.md` — skill для natural-language триггеров в Cowork
  (фразы вроде "научи p2p", "как пользоваться" сами запустят teacher)
- `!teacher.md` (820 строк) — curriculum из 5 уровней

**5 уровней:**
| # | Уровень | Время |
|---|---------|-------|
| 1 | Quickstart | 10 мин |
| 2 | Commands (11 /p2p-*) | 20 мин |
| 3 | Agents (8 QUORUM) | 30 мин |
| 4 | QUORUM Orchestration | 30 мин |
| 5 | SCOPE.HELM (большие задачи) | 45 мин |

**Команды:**
```
/p2p-teacher                 → адаптивный старт (определит твой уровень)
/p2p-teacher level=N         → прыжок на уровень
/p2p-teacher ask "вопрос"    → Q&A режим (30 FAQ покрыто)
/p2p-teacher review          → проверка пройденного
/p2p-teacher cheatsheet      → шпаргалка на одну страницу
```

Прогресс сохраняется в `_live/live_core.md`, можно проходить по частям.
Подробнее: [TEACHER_GUIDE.md](TEACHER_GUIDE.md).

## Миграция шаг за шагом

**Я ставил v8C.1 через "Upload a skill" в Cowork:**
1. Settings → Skills → удалить старый `p2p-v8c1` (или как назван)
2. `bash pack.sh` в v8C.2 → получишь `p2p-v8c2.plugin`
3. Upload a skill → выбрать `p2p-v8c2.plugin`

**Я ставил v8C.1 через Claude Code `/plugin install`:**
1. `/plugin uninstall p2p-v8c1`
2. `/plugin install /path/to/p2p-v8c2.plugin`

**Я работал через project-level (`.claude/` в проекте):**
1. Удалить старые файлы v8C.1 из проекта
2. Скопировать `cowork + code/.claude/` + корневые файлы из `for chat (project)/`

**Я работал через Claude.ai Projects:**
1. Удалить старые файлы из Project Knowledge
2. Загрузить файлы из v8C.2 (тот же список — `_preloader`, `!!core_v8C`, и т.д.)

**Я работал через API:**
1. Пересобрать `system_prompt` из новых v8C.2 файлов
   (модули с YAML version v8C.1 совместимы, можно оставить только обновлённые BASE)
