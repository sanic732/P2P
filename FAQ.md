## Установка

**Что такое P2P и зачем он?**
Модульный мета-промпт, который превращает LLM в эксперта по prompt engineering: вы описываете задачу обычным текстом, а система сама делает декомпозицию, маршрутизацию, подбор агентов и защиту от галлюцинаций. Цель — убрать ручной prompt engineering для рядового пользователя.

**Как установить?**
Три пути: (1) плагин в Claude Code/Cowork — `/plugin marketplace add <repo>` → `/plugin install p2p-v8c3@p2p`; (2) `.plugin`-файл из релиза (Cowork: Settings → Skills → Upload); (3) для любого хоста — загрузить `.md`-файлы редакции в Project Knowledge / system prompt. Триггеры запуска: `/start · start · старт · /p2p · /menu`.

**Как запустить, если хост ограничивает число файлов на сообщение?**
Прикреплять файлы в несколько подходов в один чат (не zip), либо использовать редакцию с меньшим числом файлов (8L.3 — 4 BOOT-файла). Для Qwen и подобных — добавлять файлы в проект частями. → [Запуск частями](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=143670563&anchor=Spoil-143670563-1)

**Как настроить Claude Cowork с нуля?**
Пошаговый «hot start» — в отдельном гайде. → [8 шагов настроить Cowork](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142398719)

## Использование

**Как пользоваться UI-меню? Какой пункт выбрать?**
Меню — это «пульт управления» для тех, кто любит «поковырять»; **необязательно**. Можно просто указать целевую модель и дальше писать обычным текстом — система сама применит нужную логику. Нумерация сквозная (горячий вызов), это список кнопок, а не иерархия. → [Как пользоваться UI-меню](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142199454)

**Как создавать «работу над ошибками» и собирать большие промпты?**
Вставили результат в целевую модель → не нравится → скриншот → прикрепили в тот же чат P2P → описали что не так → P2P внесёт правки. Для крупного промпта: попросить 3-4 варианта каркаса, затем mindmap + пошаговый план сборки, и только потом финальная сборка. Большие промпты собираются 3 способами (части/капсула/итерации). → [Гайд: ошибки и большие промпты](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142243608)

**Что такое Template M (Karpathy Mode)?**
Минималистичный режим «лучший промпт — чистый контекст» для простых задач (Tier 0-1), где жёсткая структура мешает модели. → [Template M](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=143033099)

**Как запускать несколько агентов параллельно?**
В 8C.3 (Claude) можно запустить несколько агентов QUORUM за один вызов. → [Параллельные агенты](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=143396222)

**Как использовать P2P с Claude Code?**
Проблема «агент пишет код с нуля» решается каталогом + скиллом и Progressive Disclosure (чтобы не читать тысячи строк при каждом старте и не ловить Lost-in-the-Middle). ТЗ встраивается в воркфлоу. → [Claude Code + P2P](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=143697302)

## Редакции и выбор

**В чём отличия редакций C / H / N / L?**
**C** — Claude-нативная; **H (High\Hybrid)** — максимум, 8 хостов (нативный Heavy-16 на Grok); **N** — универсальная под любую модель; **L** — экономная (4 BOOT + online). Подробно — [`editions/COMPARISON.md`](editions/COMPARISON.md) и [`NAMING.md`](NAMING.md). → [A/C/N/G подробно (форум)](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=137565576)

**Что значат статусы ALPHA / BETA / STABLE?**
**ALPHA** — сырая, архитектура работает, поведение в нестандартных сценариях непредсказуемо (баги — в тему). **BETA** — прошла обкатку, критических багов нет, возможны edge cases. **STABLE** — проверено временем, для прода. → [Статусы сборок](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142547413)

## Хосты

**Как запустить на Gemini? (3 способа)**
В самом чате NotebookLM — нельзя (там Gemini заточена под локальный RAG). В Gemini: (1) прикрепить файлы через «+», (2) запустить со вкладки «Блокноты», (3) добавить в Gem-бот. Прямое добавление `.md` через «+» экономнее zip (токены тратятся только на первое чтение). → [Варианты запуска на Gemini](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=143474710)

**Как запустить на Qwen?**
В проектах Qwen прописать `HOST_MODEL` в `_preloader.md`; т.к. лимит 5 файлов на сообщение — добавлять файлы в несколько подходов. Подходит 8N. → [Запуск на Qwen](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=143350627)

**В чём смысл AI Studio (Gemini) против обычного Gemini?**
В AI Studio нет soft-caps, которые в потребительском интерфейсе срезают качество ответов; сборки A расширены по функционалу. → см. [`NAMING.md`](NAMING.md)

**Что реально работает на Qwen/Gemini, а что псевдо-эффект?**
Разбор «под капотом» — какие приёмы дают эффект, а какие плацебо. → [QWEN report](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=139778198)

## Токены и лимиты

**Как экономить токены в Gemini через NotebookLM?**
Загрузить базу P2P в NotebookLM как источник — резко снижает расход токенов в Gemini. → [Экономия через NotebookLM](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=143234252&anchor=Spoil-143234252-1)

**Как устроены контекст, токенизация и zip-сжатие?**
Важен не объём zip, а суммарный объём токенов после декомпрессии. LLM сканирует дерево архива (CONTEXT_SCAN), помечает как статический контекст (CONTEXT_CACHE) — экономия на повторных запросах. zip удобен, но «съедает» токены при каждом возврате в чат; прямое добавление `.md` — только первое чтение. → [Контекст, токенизация и zip](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142276672)

**Сколько токенов на старте у редакций?**
C: ~7K→59K · H/N: ~60K→200K · L: ~18K (старт)→57K. См. [`editions/COMPARISON.md`](editions/COMPARISON.md).

## Обновления и Live Specs

**Что такое Live Specs и как обновлять?**
Авто-обновляемый справочник цен/квот/багов моделей. В поколении .3 — из выделенного Gist (`live_specs.md`, latest): система на старте проверяет web-fetch и тянет свежие данные, иначе работает из вшитого snapshot. → [Live Specs — постоянная ссылка](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142685423)

**Как обновлять P2P при выходе новой версии?**
Для плагина — `/plugin update p2p-v8c3@p2p`. Для чата — заменить файлы редакции и написать `full ui menu` (дата/версия обновятся). → [Гайд: обновления](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142243608)

## Траблшутинг

**Почему глобальные Custom Instructions ломают агентов P2P?**
Системные инструкции профиля имеют наивысший приоритет внимания и «оборачивают» ядро P2P, переопределяя поведение агентов (напр. ANON-кодер начинает добавлять лишнее). Решение — изолировать P2P от глобальных настроек (4 способа в посте). → [Персонализация аккаунта и P2P](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142364315&anchor=Spoil-142364315-1)

**Не отображается меню?**
Напишите `full ui menu` (или `ui menu`) — интерфейс выведется первым сообщением.

**Как убрать «фантазии» / галлюцинации модели?**
Режим отладки + FIX-Patch: правит любой промпт «на лету» под задачу, снижает выдумывание. → [Режим отладки + FIX](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142239341)

**Как сравнить и протестировать промпты?**
ARENA v3.0 — A/B-тест с trap-маркерами и числовой оценкой. → [ARENA Builder](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142252035)

## Безопасность

**Почему джейлбрейки убивают аккаунты?**
Инфраструктура провайдеров — частная; регулярные обходы фильтров дают статус High Risk («чёрная метка»), деанон по фингерпринту (VPN не спасает). Не используйте основной аккаунт для тестов фильтров; легальная альтернатива — white-hat песочница. → [Jailbreak и иллюзия контроля](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142093413)

**Что такое легальный (White Hat) промпт-инжиниринг?**
Подборка приёмов, работающих без нарушения правил провайдеров. → [White Hat Prompt Engineering](https://4pda.to/forum/index.php?showtopic=1109539&view=findpost&p=142218452)
